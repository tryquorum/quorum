# ADR-0002 — 메타데이터 결정

- 소유 문서: [contracts.md](../contracts.md)
- 커밋: `eaa8607`.

## 결정 기록

- 목적과 의도: 문서의 기본 정보와 사용자 속성을 읽고 고칠 수 있게 해요.
- 기존 구현 및 제약: 기존 문서 계약에는 사용자 속성과 편집기 원문이 없었어요.
- 검토한 대안: 기록에 없음.
- 선택: 예약된 기본 메타와 타입이 정해진 사용자 속성, 편집기 원문을 분리해요.
- 이유: 기본 정보와 사용자가 정한 정보를 충돌 없이 공유하기 위해서예요.
- 장단점과 영향: 검색·거울·버전 충돌 처리에도 계약이 적용돼요.
