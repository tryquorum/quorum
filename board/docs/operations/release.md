# 릴리스

1. 변경된 계약과 서버가 기존 웹·모바일 클라이언트를 계속 받을 수 있는지 먼저 확인해요. 호환이 필요한 계약은 서버를 먼저 배포해요.
2. 웹을 빌드하고 서버가 올바른 정적 파일을 가리키는지 확인해요. 서버 재시작 권한과 진행 중 AI 상태를 확인한 뒤 배포해요.
3. 배포된 서버의 인증, 웹의 읽기·쓰기와 필요한 입구를 실제 클라이언트에서 확인해요. 실패 시 이전 버전과 데이터의 호환성을 확인하고 되돌려요.
4. 모바일은 [TestFlight 절차](mobile-testflight.md)를 따라 별도로 배포해요. 이 문서는 다른 레인에서 작성 중이에요.

현재 배포 준비 상태와 경로는 [배포 안내](deploy.md)를 보세요.
