# 거울 충돌 해소

방향판은 DB를 원본으로 삼고 마크다운 거울을 밖에서 고친 흔적이 있으면 덮어쓰지 않아요. 부모를 옮기거나 이름을 바꿀 때도 충돌한 문서만 이전 경로에 남고 다른 문서는 각자 처리될 수 있어요.

1. 로그에서 거울 쓰기 실패를 확인해요. DB를 읽기 전용으로 열어 `doc_mirror_state`에서 `sig='!retry'`인 `owner`·`ref`를 찾고, vault의 `.vault-ledger.json`에서 같은 `owner`·`ref`의 `path`를 확인해요. 그 파일과 방향판 문서의 내용을 비교해요. 거울 재구축도 바깥에서 고친 파일을 덮어쓰지 않아요.
2. 보존할 내용은 방향판 문서에 직접 옮겨 적어요. 그런 다음 해당 거울 파일을 마지막으로 방향판이 쓴 내용 그대로 되돌려요. 파일을 되돌리기 전에 사람의 변경 내용을 따로 보존해요.
3. 다음 거울 재시도를 기다리고 새 경로와 내용이 맞는지 확인해요. 계속 실패하면 로그와 파일 상태를 다시 살펴요. DB나 ledger를 직접 고쳐 충돌을 감추지 않아요.
