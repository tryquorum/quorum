# 로컬 개발

[설정 예시](../../.env.example)를 `.env.local`로 복사하고 필요한 값을 채워요. 비밀값은 공유하거나 커밋하지 않아요. 현재 `bun run dev`는 watch로 서버를 띄우고, `bun run web:dev`는 Vite 화면과 API 프록시를 써요. 기본 예시 포트 3070이 사용 중이면 별도 포트로 설정해요.

워크트리마다 별도 `DB_PATH`, 포트, `VAULT_DIR`를 정해요. 실제 DB는 읽기나 일관된 복사에만 사용하고 쓰기 실험은 복사본이나 `:memory:`에서 해요. 서버는 시작하면서 색인·거울을 쓸 수 있으니 실데이터를 가리킨 채 시작하지 않아요. 이미 실행 중인 3070 서버는 건드리지 않아요.
