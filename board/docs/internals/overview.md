# 구조와 흐름

사건을 받는 곳과 사람이 쓰는 곳은 달라도 원본은 서버의 SQLite예요. 문서 색인과 마크다운 거울은 원본을 찾고 읽기 위한 파생물이에요. 거울을 직접 고쳐도 DB로 돌아오지 않아요. 사람이 쓴 노트를 AI가 교체하려 하면 제안으로 남기는 이유도 같은 원본을 보호하기 위해서예요. 자세한 계약은 [문서 층 설계](docs-layer.md)를 보세요.

서버 실행과 화면, 운영 순회와 에이전트는 각각 실패할 수 있어요. 한 경로가 성공했다고 다른 입구나 외부 수집이 동작한다고 판단하지 않아요. 현재 경계는 [구조 지도](../../structure/INDEX.md), 바꿀 경로는 [이동 계획](../../devlog/_plan/261106_monorepo/README.md)에 있어요.
